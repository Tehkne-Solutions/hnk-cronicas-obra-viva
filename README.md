## Princípios de arquitetura

- World Truth não é Persona Knowledge.
- A alquimia é baseada em regras, não em receitas rígidas.
- A narrativa é composta a partir da percepção da Persona.
- A Crônica persiste além de uma Persona.
- Henuvokodan não é moeda, rank, energia ou recurso farmável.
